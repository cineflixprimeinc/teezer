# Licensing key material

## `public.pem` — ships to customers

The RSA **public** verification key. This file is *meant* to be distributed:
it can verify a licence signature and cannot produce one. Every customer
installation carries a copy and uses it to check its licence entirely offline,
with no call to teezer.live.

It is generated by `php artisan license:keygen`, which writes it here.

## The private key — never ships, never commits

The matching **private** key lives at
`/etc/teezer/license-signing-key.pem` (see `LICENSE_SIGNING_PRIVATE_KEY_PATH`),
outside this repository, mode `0600`.

It must never appear in:

- this repository or any Git history
- a marketplace package
- an installer
- a customer VPS
- a frontend bundle
- a log file, error report or backup that anyone else can read

If it leaks, anyone can mint valid licences for the product and the only remedy
is generating a new keypair — which invalidates **every licence ever issued**,
because each installation verifies against the old public key.

Back it up offline and encrypted. Losing it means no existing customer can ever
renew, and no new licence can be issued.
